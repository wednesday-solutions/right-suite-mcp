# Right Suite for Hermes Agent

![Right Suite](assets/catalog.png)

Test your price, landing page, cold email, ads and positioning on 100+ AI-simulated buyers from
Hermes. Tell the agent what you sell and who buys it, and Right Suite shows it to simulated buyers
modelled on that audience. In 10 to 20 minutes you get a verdict, the main objections and what to
change.

Needs a Right Suite account with credits. You sign in with your Right Suite account in your browser.

This package connects Hermes to Right Suite's hosted MCP server at
`https://www.rightsuite.co/api/mcp` (Streamable HTTP, OAuth) and adds one skill,
`right-suite:right-suite`, that tells the agent which test to run and how to read the report.

## Install

```bash
hermes plugins install right-suite
hermes plugins enable right-suite
```

## Sign in (once)

Agent Plugins v1 packages cannot ask Hermes for OAuth, so the sign-in uses a normal Hermes server
entry with the same name. Add this to your profile's `config.yaml` (replace any existing
`right-suite` entry as a whole):

```yaml
mcp_servers:
  right-suite:
    url: "https://www.rightsuite.co/api/mcp"
    auth: oauth
    trust: untrusted
```

Then run:

```bash
hermes mcp login right-suite
```

Your browser opens Right Suite's consent page, which shows that Hermes Agent is asking for access.
Sign in and click **Allow**. Hermes stores and refreshes the sign-in itself; this package never sees
it. Check it with `hermes mcp test right-suite`, then start a new session.

Keep `trust: untrusted` in the entry above. With it, Hermes asks you before every tool that spends
credits (see the table below) and refuses those tools in unattended runs such as cron.

## Tools

The server provides these tools at run time.

| Tool | Read or write | Hermes asks first? | What it does |
|---|---|---|---|
| `get_credits` | Read | No | Your plan and credits left. |
| `list_runs` | Read | No | Your recent runs. |
| `get_report` | Read | No | Live progress (step, new buyer reactions with quotes, what they got stuck on), then the finished report. |
| `test_price` | Write (credits) | Yes | Starts a price test. |
| `test_landing_page` | Write (credits) | Yes | Starts a landing page or marketing copy test. |
| `test_cold_email` | Write (credits) | Yes | Starts a cold email or DM test. |
| `test_ad` | Write (credits) | Yes | Starts an ad test. |
| `find_audience` | Write (credits) | Yes | Starts a run comparing customer segments. |
| `test_positioning` | Write (credits) | Yes | Starts a run against named competitors. |
| `pick_channel` | Write (credits) | Yes | Starts a run ranking marketing channels. |

Each run costs 1 to 3 credits. No tool changes or deletes existing data.

## Disclosure

- **Hosted-only connector.** This package is configuration and Markdown only: `plugin.json`,
  `mcp.json`, one skill and this README. It contains no code that runs on your machine, starts no
  local process, reads no files outside its own folder, and sends no telemetry of its own.
- **Network.** Every tool call goes to Right Suite at `https://www.rightsuite.co`, run by Wednesday
  Solutions. The offer, copy, ad, competitor names and audience you ask it to test are sent there.
- **Sign-in.** You sign in through Right Suite's OAuth server in your browser. Hermes stores the
  resulting token under its own MCP token store.
- **AI models.** Simulated buyers are generated by AI models that Right Suite calls on its side.
- **Costs.** Run tools spend your Right Suite credits. Read tools are free.
- **Your data.** Reports stay on your Right Suite dashboard. To have your data deleted, email
  [support@rightsuite.co](mailto:support@rightsuite.co).
- **Not pinned.** The tool set is served by the remote server at run time and is not covered by
  the commit this package is pinned to in the Hermes catalog.

## Troubleshooting

| Symptom | Fix |
|---|---|
| No Right Suite tools in a session | Run `hermes plugins list` and `hermes mcp list`, check the sign-in step above, then start a new session. |
| `hermes mcp test right-suite` says the server is not configured | Add the `config.yaml` entry from "Sign in (once)". |
| Sign-in stopped working | Run `hermes mcp login right-suite` again. |
| A run fails for lack of credits | Check `get_credits`, then pick a plan at https://www.rightsuite.co. |
